# Connecting an ASIC Miner to AMS

To connect devices to AMS, you first need to perform the following steps:

- Register an account on the website [ams.bixbit.io](http://ams.bixbit.io)
- Create a **Workspace** in your AMS personal account
- In the created space, go to the "**Workspace**" tab
- Copy the **API key**. This key will be used to connect devices later.

  ![Automate Monitoring System workspace settings, General tab: API KEY field with copy button, workspace title and description](/images/image-71.png)

## Antminer ASIC

### On BiXBiT Firmware

1. In the **device's web interface**, go to the "**AMS**" tab.
2. Enter the previously copied **AMS Workspace key** into the "**API key**" field.
3. Click the **Install** button.
  ![AMS tab in BiXBiT firmware on Antminer: How to connect steps, API KEY field and Install button](/images/image-72.png)
4. Wait until the **Install** button is replaced by the **Uninstall** button. After that, the device will appear in the "**Miners**" tab.
  ![AMS tab after connection: API key saved, the Install button replaced by Uninstall](/images/image-73.png)

### On Stock or Third-Party Firmware

To be added with the release of AMS Hub.

## Whatsminer ASIC

### On BiXBiT Firmware

![Whatsminer BiXBiT firmware, AMS (control & monitoring) tab: Install AMS Monitoring steps, API Key field, Install](/images/image-66.png)

1. In the **device's web interface**, go to the "**AMS (control & monitoring)**" tab.
2. Enter the previously copied **AMS space key** into the "**API Key**" field.
3. Click the **Install** button.
4. Wait for the "**Installed**" message. After that, the device will appear in the "**Miners**" tab.

### On Stock or Third-Party Firmware

To be added with the release of AMS Hub.
