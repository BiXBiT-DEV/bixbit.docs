# System Section

This section has 2 subsections:

- **Password** — here you can change the password for the device's web interface.
- **Firmware upgrade** — in this section, you can install factory firmware using the appropriate BMU file. The difference from the **Stock FW** button is that the button restores the factory firmware that was on the device immediately before installing the BiXBiT firmware, whereas through this subsection you can install any factory firmware file and, using the **Clear logs** checkbox, ++remove traces of the BiXBiT firmware installation++.
