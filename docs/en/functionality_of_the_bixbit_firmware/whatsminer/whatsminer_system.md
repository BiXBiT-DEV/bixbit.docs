# System Section

This section contains three subsections:

- **System** — in this subsection, you can set the time on the device, select the time zone, and specify NTP server addresses for automatic time synchronization.
- **Administration** — in this section, you can change the password for the current account.
- **Reboot** — a section where you can restart the device.
