# Configuring DNS in Case of Connection Issues with AMS

## Antminer

The DNS server address can be specified on the device only when the protocol is set to **[Static](https://bixbit-dev.github.io/bixbit.docs/ru/Functionality%20of%20the%20BiXBiT%20firmware/Antminer/Antminer%20IP%20Settings.html)**.

In the DNS Server field, you must specify the address **95.163.222.17** first. Optionally, you can add another DNS server address separated by a comma, for example, **8.8.8.8**.

Example entry: "95.163.222.17, 8.8.8.8"

## Whatsminer

The DNS server address can be specified on the device only when the protocol is set to **[Static Address](https://bixbit-dev.github.io/bixbit.docs/ru/Functionality%20of%20the%20BiXBiT%20firmware/Whatsminer/Whatsminer%20Configuration.html#%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B8-%D1%81%D0%B5%D1%82%D0%B8)**.

In the Use Custom DNS Servers field, you must specify the address **95.163.222.17** first. Optionally, you can add another DNS server address, for example, **8.8.8.8**.
