## REQUIRED HARDWARE:

- A power supply network, wiring, and circuit breakers (protective breakers) corresponding to the device's specifications.
- A router with internet access.
- A computer connected to this router.
- An Ethernet cable ("twisted pair"/"patch cord") for connecting the ASIC miner to this router.
- In some cases, a microSD card may be required. It is recommended to use SD cards with a capacity ranging from 2GB to 16GB.

::: tip
The device does not have a wireless communication module and requires an Ethernet cable connecting it to the router / switch / modem on this network.   
Important: your computer must be on the same local network as the ASIC miner.
:::
