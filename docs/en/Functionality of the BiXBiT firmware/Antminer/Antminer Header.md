# Device Top Control Panel

![image.png](/images/image-33.png)

This panel allows you to view the current device status and perform basic device management:

1. Current device status.
2. Device model.
3. Control board model.
4. Power supply model.
5. Find Device — a function that causes the LEDs on the control board to blink.
6. Stock FW — a function to roll back to the factory firmware. Restores the factory firmware that was on the device before installing BiXBiT.
7. Restore Factory Settings — a function that resets the device settings to default.
8. Reboot — a function to restart the device.
9. Restart Miner — a function that restarts the mining process on the device.
10. Sleep — a function that puts the device into sleep mode.
11. Web interface language switch.
