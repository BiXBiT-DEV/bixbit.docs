# Sección System

Esta sección contiene tres subsecciones:

- **System** — en esta subsección puede configurar la hora del dispositivo, seleccionar la zona horaria e indicar las direcciones de los servidores NTP para la sincronización automática de la hora.
- **Administration** — en esta sección puede cambiar la contraseña de la cuenta actual.
- **Reboot** — sección en la que puede reiniciar el dispositivo.
