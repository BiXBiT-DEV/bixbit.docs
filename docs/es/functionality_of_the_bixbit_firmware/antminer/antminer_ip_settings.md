# Sección IP Settings

En esta sección puede configurar la asignación automática de la dirección IP del dispositivo o establecer una dirección IP estática.

![IP Settings del firmware BiXBiT en Antminer: información de red, nombre de host, protocolo DHCP/Static, IP, máscara de subred, puerta de enlace, DNS](/images/ip-settings.png)

1. **Network information** — información sobre la conexión actual (dirección MAC del dispositivo, dirección IP del dispositivo, máscara de subred).
2. **Hostname** — nombre del dispositivo en la red. El dispositivo se mostrará con este nombre en la red local del router.
3. **Protocol** — protocolo de asignación de la dirección IP. Puede ser: DHCP (asignación automática de la dirección IP por parte del router) o Static — dirección IP configurada de forma estática.
4. **IP address** — campo para indicar la dirección IP del dispositivo. Se rellena cuando se configura el protocolo Static.
5. **Subnet mask** — máscara de subred. Se rellena cuando se configura el protocolo Static.
6. **Gateway** — dirección de la puerta de enlace (normalmente la primera dirección de la subred). Se rellena cuando se configura el protocolo Static.
7. **DNS Server** — dirección del servidor DNS; puede indicar varias separadas por comas. Se rellena cuando se configura el protocolo Static.
