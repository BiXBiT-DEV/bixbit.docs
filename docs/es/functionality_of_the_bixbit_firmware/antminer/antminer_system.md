# Sección System

Esta sección tiene 2 subsecciones:

- **Password** — aquí puede cambiar la contraseña de la interfaz web del dispositivo.
- **Firmware upgrade** — en esta sección puede instalar el firmware de fábrica mediante el archivo BMU correspondiente. La diferencia con el botón **Stock FW** es que el botón restaura el firmware de fábrica que tenía el dispositivo justo antes de instalar el firmware BiXBiT, mientras que a través de esta subsección puede instalar cualquier archivo de firmware de fábrica y, marcando la casilla **Clear logs**, ++eliminar los rastros de la instalación del firmware BiXBiT++.
