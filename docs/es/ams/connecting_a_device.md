# Conexión de un minero ASIC a AMS

Para conectar dispositivos a AMS, primero debe realizar los siguientes pasos:

- Registre una cuenta en el sitio web [ams.bixbit.io](http://ams.bixbit.io)
- Cree un **Workspace** en su cuenta personal de AMS
- En el espacio creado, vaya a la pestaña "**Workspace**"
- Copie la **API key**. Esta clave se utilizará más adelante para conectar los dispositivos.

  ![Configuración del workspace de Automate Monitoring System, pestaña General: campo API KEY con botón de copiar, título y descripción del workspace](/images/image-71.png)

## ASIC Antminer

### Con firmware BiXBiT

1. En la **interfaz web del dispositivo**, vaya a la pestaña "**AMS**".
2. Introduzca la **clave del Workspace de AMS** copiada previamente en el campo "**API key**".
3. Haga clic en el botón **Install**.
  ![Pestaña AMS en el firmware BiXBiT para Antminer: pasos How to connect, campo API KEY y botón Install](/images/image-72.png)
4. Espere hasta que el botón **Install** sea reemplazado por el botón **Uninstall**. Después de eso, el dispositivo aparecerá en la pestaña "**Miners**".
  ![Pestaña AMS tras la conexión: API key guardada, el botón Install reemplazado por Uninstall](/images/image-73.png)

### Con firmware de fábrica o de terceros

Se añadirá con el lanzamiento de AMS Hub.

## ASIC Whatsminer

### Con firmware BiXBiT

![Firmware BiXBiT para Whatsminer, pestaña AMS (control & monitoring): pasos Install AMS Monitoring, campo API Key, Install](/images/image-66.png)

1. En la **interfaz web del dispositivo**, vaya a la pestaña "**AMS (control & monitoring)**".
2. Introduzca la **clave del espacio de AMS** copiada previamente en el campo "**API Key**".
3. Haga clic en el botón **Install**.
4. Espere al mensaje "**Installed**". Después de eso, el dispositivo aparecerá en la pestaña "**Miners**".

### Con firmware de fábrica o de terceros

Se añadirá con el lanzamiento de AMS Hub.
