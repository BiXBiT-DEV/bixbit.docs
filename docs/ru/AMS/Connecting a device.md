# Подключение ASIC-майнера к AMS

Для подключения устройств к AMS первоначально нужно выполнить следующие действия:

- Зарегистрировать учетную запись на сайте [ams.bixbit.io](http://ams.bixbit.io)
- Создать **пространство** в личном кабинете AMS
- В созданном пространстве перейти на вкладку "**Пространство**"
- Скопировать API ключ. В дальнейшем с помощью данного ключа будут подключаться устройства
![image.png](/images/image-67.png)

## Antminer ASIC

### На прошивке BiXBiT

![image.png](/images/image-69.png)

1. В **web-интерфейсе устройства** перейдите на вкладку "**AMS**"
2. Введите ранее скопированный **ключ пространства AMS** в поле "**API ключ**"
3. Нажмите кнопку **Подключить**
4. Дождитесь когда кнопка **Подключить** заменится кнопкой **Отключить** . После этого устройство появится во вкладке "**Майнеры**"
  ![image.png](/images/image-70.png)

### На заводской или сторонней прошивке

Будет дополнено с релизом AMS Hub

## Whatsminer ASIC

### На прошивке BiXBiT

![image.png](/images/image-66.png)

1. В **web-интерфейсе устройства** перейдите на вкладку "**AMS (control & monitoring)**"
2. Введите ранее скопированный **ключ пространства AMS** в поле "**API Key**"
3. Нажмите кнопку **Install**
4. Дождитесь сообщения "**Installed**". После этого устройство появится во вкладке "**Майнеры**"

### На заводской или сторонней прошивке

Будет дополнено с релизом AMS Hub
