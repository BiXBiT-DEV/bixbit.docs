# Базовая настройка ASIC-майнера

## НЕОБХОДИМОЕ АППАРАТНОЕ ОБЕСПЕЧЕНИЕ

- Соответствующая характеристикам устройства мощность питающей сети, проводка и автоматические выключатели (автоматы защиты).
- Маршрутизатор с доступом к интернету.
- Компьютер, подключенный к данному маршрутизатору.
- Кабель Ethernet (“витая пара”/“патч-корд”) для подключения ASIC-майнера к данному маршрутизатору.
- В некоторых случаях может понадобиться microSD-карта. Рекомендуется использовать SD-карты объемом от 8 до 16 ГБ включительно. Для устройств, в которых контрольные платы оборудованы только разъемом MicroUSB, дополнительно потребуется переходник и картридер

::: info
Устройство не имеет беспроводного модуля связи и требует наличия Ethernet кабеля , соединяющего его с маршрутизатором / коммутатором(“свичем”) / модемом в данной сети. Важно: ваш компьютер должен находиться в той же локальной сети, что и ASIC-майнер.
:::

## НЕОБХОДИМОЕ ПРОГРАММНОЕ ОБЕСПЕЧЕНИЕ

### Для устройств Whatsminer:

- **WhatsMinerTool.** Скачать последнюю версию WhatsMinerTool можно по ссылке: [WhatsMinerTool](https://www.whatsminer.com/src/views/firmware-download.html#Tool). Использование устаревших версий может привести к неудачной установке прошивки.
- **Прошивка BiXBiT**, соответствующая устройству [Whatsminer](https://bixbit.tech/ru/firmwares#firmware-whatsminer) 

- Любой Интернет-браузер.

### Для устройств Antminer:

- **BTC Tools.** Скачать последнюю версию BTC Tools можно по ссылке: [https://btc-tools.org/](https://btc-tools.org/)
- **Прошивка BiXBiT**, соответствующая устройству [Antminer](https://bixbit.tech/ru/firmwares#firmware-antminer).
- **IPReporter.exe**. Для случаев когда вы не знаете IP-адрес асика: [IP Reporter.zip](https://assets-product.bitmain.com.cn/shop-product-s3/firmware/IP%20Reporter.zip) 
- Любой Интернет-браузер.
