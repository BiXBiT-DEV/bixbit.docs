# Раздел System

В данном разделе имеется 2 подраздела:

- **Passwrod** - здесь можно изменить пароль от web-интерфейса устройства
- **Firmware upgrade** - в этом разделе можно с помощью соответствующего bmu-файла установить заводскую прошивку. Отличие от кнопки **Stock FW** в том, что кнопка возвращает заводскую прошивку, которая стояла на устройстве непосредственно перед установкой прошивки BiXBiT, а через данный подраздел можно установить любой файл заводской прошивки и, с помощью чекбокса **Clear logs**, ++удалить следы установки прошивки BiXBiT++
