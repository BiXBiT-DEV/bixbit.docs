# Раздел IP Settings

В данном разделе можно настроить автоматическое получение IP-адреса для устройства, или настроить статический IP-адрес.

![IP Settings.png](/images/ip-settings.png)

1. **Network information** - информация о текущем подключении (MAC-адрес устройства, IP-адрес устройства, маска подсети)
2. **Hostname** - имя устройства в сети. Под этим именем устройство будет отображаться в локальной сети маршрутизатора
3. **Protocol** - протокол получения IP-адреса. Может быть: DHCP (автоматическое получение IP-адреса от маршрутизатора) или Static - статически настроенный IP-адрес
4. **IP address** - поле для указания IP-адреса устройства. Заполняется в случае настройки протокола Static
5. **Subnet mask** - маска подсети. Заполняется в случае настройки протокола Static
6. **Gateway** - адрес шлюза (чаще всего это первый адрес в подсети). Заполняется в случае настройки протокола Static
7. **DNS Server** - адрес DNS-сервера, можно указать несколько через запятую. Заполняется в случае настройки протокола Static
