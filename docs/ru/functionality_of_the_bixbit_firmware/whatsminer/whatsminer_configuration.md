# Раздел Configuration

## Interfaces

В данном разделе можно посмотреть сетевую статистику и изменить настройки сети для устройства

### Статистика

![{FDA74569-4E91-440D-B193-8303E932648A}.png](/images/fda74569-4e91-440d-b193-8303e932648a.png)

- **Uptime** - время "жизни" текущего соединения с маршрутизатором
- **MAC-Address** - MAC-адрес устройства
- **RX** - количество полученных из сети данных (в скобочках указано число пакетов)
- **TX** - количество переданных в сеть данных (в скобочках указано число пакетов)
- **IPv4** - IP-адрес устройства в локальной сети

### Настройки сети

Для настройки статического адреса последовательно выполните следующие действия:

- Нажмите кнопку **Edit** напротив LAN-интерфейса
- На открывшейся странице в поле **Protocol** выберите **Static Address**
- Нажмите кнопку **Switch Protocol**

Далее необходимо указать в полях настройки для работы статического **IP-адреса:**

![{7612826C-C6C6-429B-9A32-0B25F224EEBA}.png](/images/7612826c-c6c6-429b-9a32-0b25f224eeba.png)

- **IPv4 address** - IP-адрес вашего ASIC-майнера в локальной сети
- **IPv4 netmask** - маска подсети, в которой должен находиться заданный выше IP-адрес
- **IPv4 gateway** - IP-адрес шлюза. Обычно это первый IP-адрес в диапазоне
- **IPv4 broadcast** - широковещательный IP-адрес. Обычно это последний IP-адрес в диапазоне
- **Use custom DNS servers** - IP-адреса DNS-серверов

## Miner Configuration

В этом подразделе собраны все настройки майнинга на устройстве

### Вкладка Pool

На этой вкладке вы можете указать данные для подключения к пулам. Поддерживается до 3 пулов

![image.png](/images/image-57.png)

- **Coin Type** - любой поддерживаемый вашим пулом на основе алгоритма SHA-256
- **Pool 1/2/3** - адрес пула. Для указания собственного пула необходимо выбрать пункт --custom-- и ввести адрес пула в этой же поле
- **Pool 1/2/3 worker** - имя воркера для данного пула
- **Pool 1/2/3 password** - пароль для воркера данного пула (опционально, в зависимости от пула)

### Вкладка Overclock

На данной вкладке находятся различные опции предназначенные для разгона устройства

![image.png](/images/image-58.png)

#### Liquid Cooling

Данный чекбокс предназначен для **перевода устройства на иммерсионный режим охлаждения**.  
При активации данного чекбокса, кулеры устройства перестают проверяться программно. Обычно используется в связке с **[Disable Power Fan]**

::: info

- При активации данного режима (во вкладке Miner Status → Summary) параметр Fan Speed меняется на Liquid Cooling;
- Если включить данный режим и оставить кулера на устройстве – они будут крутиться, однако устройство не сможет влиять на их скорость вращения;
- Данная функция может использоваться также и для охлаждения устройства не штатными кулерами.
:::

#### Additional PSU

Данный режим предназначен для подключения к устройству **дополнительного блока питания**.

#### Startup Cooling Fan Speed %

Данный параметр предназначен для настройки скорости вращения кулеров (в процентах) с момента окончания продувки (обороты кулеров – 100%) до момента начала работы устройства. С какой скорости устройство начинает охлаждение. <u>Не отключает начальную продувку устройства – то есть, шуметь при запуске будет в любом случае.</u>

#### Fan Mode

Данная функция предназначена для переключения режима работы кулеров. Имеет два состояния:

- **[Auto]** – скорость вращения кулеров будет определяться автоматически.
- **[Manual]** – максимальная скорость вращения кулеров будет ограничена параметром **[Manual Fan Speed]**.

#### Manual Fan Speed %

В случае если установлен ручной режим охлаждения, **данный показатель является ограничителем максимальной мощности кулеров устройства**.

В случае если при работе устройства в данном режиме оно начнет перегреваться, устройство выйдет из режима ручного управления вентиляторами и начнет управлять ими в автоматическом режиме

#### Current Profile

Выбор профиля разгона для устройства. Профиль содержит в себе информацию по частоте чипов, напряжению, целевым температурам и лимитам по потреблению для начала **Autotune** - процесса подбора оптимальных частот и напряжения в соответствии с целевыми показателями и условиями работы устройства

#### Lower Profile if Autotune Failed

При активации данной опции, в случае если устройство не смогло завершить **Autotune** на выбранном профиле, оно автоматически понизит профиль и начнет процесс **Autotune** на нем.

#### Advanced Options

Меню ручной настройки разгона для опытных пользователей. В большистве случаев рекоменудется использовать сгенерированные профили разгона.

::: info
Значения, отображаемые в полях данного раздела, зависят от выбранного сгенерированного профиля и автоматически обновляются при его смене. Если вы вручную измените эти значения, они будут иметь приоритет над параметрами выбранного ранее профиля. Поэтому, чтобы избежать случайного применения вручную введённых данных при разгоне устройства, рекомендуется повторно выбрать нужный профиль разгона и отключить флажок **Advanced options**.
:::

- **Target Frequency:** искомая средняя частота чипов на платах, к которой будет стремиться майнер в процессе автонастройки.
- **Target Voltage:** искомое напряжение, подаваемое на платы, к которому стремится майнер в процессе автонастройки
- **Minimum Voltage:** Минимальное напряжение, которое применит к платам майнер при автонастройке.
- **Maximum Voltage:** Максимальное напряжение, которое применит к платам майнер при автонастройке.
- **Target Board Temp:** Не рекомендуется изменять. Температура платы, на которую ориентируется майнер при автонастройке и работе. В случае невозможности удержать температуру до указанного значения - майнер допустит отклонение до максимально возможной (85), после чего будет снижать частоту работы чипов и, соответственно хешрейт.
- **Chip Ok Percent:** Не рекомендуется изменять.
- **PSU Power Limit:** Мощность потребления в ваттах, к которой будет стремиться майнер. Может превышать указанное значение при работе, но не более PSU Power Max. Рекомендуемое значение - на 100-200 Ватт меньше PSU Power Max, но **не более 3800-3900 Вт**.
- **PSU Power Max:** Предельно допустимая мощность потребления. При превышении этого значения Майнер выдаст ошибку. Рекомендуемое значение - не более заявленной мощности блока питания майнера. Как правило это 3900-4000 Вт.
- **PSU Power Rate:** Не рекомендуется изменять.

В столбцах справа вы можете видеть подсказку для выбранного профиля в виде: **Default** - значение по умолчанию, **Min** - минимально возможное и **Max** - максимально возможное значение в поле.

В процессе разгона необходимо следить за температурой чипов (не путать с температурой плат, которая отображается в веб-интерфейсе в колонке **ChipTemp**)

Эту температуру можно увидеть в столбце **ChipTemp** утилиты **WhatsMinerTool:**

![image.png](/images/image-59.png)

В настройках утилиты предварительно необходимо параметр **List Column Display Mode** установить в “**Complete Mode**”, в противном случае колонка **ChipTemp** отображаться не будет.

Расшифровка значения строки “**116.0_72.1_93.8**”: **максимальная** (116.0), **минимальная** (72.1) и **средняя** (93.8) температура чипов майнера.

::: warning
Допустимый производителем рабочий предел температуры для чипов индивидуален для разных моделей майнера, при ее превышении майнер снижает частоту чипов. **Не смотря на то, что температура считается допустимой, не рекомендуется эксплуатировать майнер при таких условиях во избежании неисправностей**.
:::

::: info
Ошибка **Restart As Hashrate Error** – встречается на устройствах серии M2X, исправляется с помощью ввода в **Minimum Voltage** значения указанного в скобках одноименной ошибки в System.log (expect vol:…).
В таких случаях, также требуется поднять **Target**, и **Maximum Voltage** на **50**, и **100** от **Minimum** соответственно.
:::



#### Generate Profiles/Stop profiles generation/Regenerate Profiles

Данная кнопка имеет 3 состояния:

- **Generate Profiles** – данная кнопка отображается по умолчанию. При нажатии **начинается процесс генерации профилей**, список профилей и активный профиль можно увидеть в поле **[Current profile]**;
- **Regenerate Profiles** – данная кнопка отображается в случае если процесс генерации профилей завершился успешно. При нажатии **процесс генерации профилей начинается заново**;
- **Stop profiles generation** – данная кнопка отображается в случае если процесс генерации профилей не завершился. При нажатии **процесс генерации профилей останавливается**.

#### Delete Autotune Results

Удаляет результаты автотюна. (Данная кнопка может отсутствовать, в случае если устройство ещё ни разу не завершало тюн)

### Вкладка Profile Switcher

**Profile Switcher** - функция автоматической смены профилей при достижении заданных температур чипов. Для работы данной функции указываются значения при которых будет происходить переключение профиля, вверх или вниз. В Maximum Profile - указывается максимальный профиль выше которого устройство не будет поднимать профиль разгона. При каждом переключении профиля, устройство будет перезагружаться и запускать Autotune на новом профиле

![image.png](/images/image-61.png)

- **Enable Profile Switcher** – чекбокс включения / отключения опции Profile Switcher.
- **Maximum Profile** – максимальный профиль на который может переключиться устройство.
- **Lower Profile if Max Chip Temp Above** – температура понижения профиля. При достижении данной температуры **одним из чипов**, устройство понизит профиль до предыдущего.
- **Raise Profile if Max Chip Temp Below** – температура повышения профиля. При охлаждении **самых горячих чипов** до данной температуры, устройство **повысит профиль** до следующего.
- **Ignore PWM** – игнорировать обороты кулеров. В случае, если температурный режим подходит для повышения профиля, устройство сделает это даже при высоких оборотах кулеров. 

### Вкладка Hotel Fee

Функция позволяет указать пул и процент для дополнительных отчислений. При включенной функции указанный процент хешрейта будет уходить на указанный в этой вкладе адрес

![Скриншот сделанный 2026-08-12 в 12.40.16.png](/images/skrinshot-sdelannyj-2026-08-12-v-124016.png)

Пример: на представленном выше скриншоте функция включена, заданы данные для подключения к пулу и процент отчислений (45%). Значит, что хешрейт устройства поделится на два пула в следующем соотношении: 45% уйдет на пул Hotel Fee, 55% (100%-45%) - уйдет на основные пулы, указанные на вкладке **Configuration - Miner Configuration - Pool**

- Enabled - включение/выключение функции
- URL - адрес пула, указывается вместе со схемой (в данном случае "stratum+tcp://") и портом (в данном случае "443")
- User - имя вокера на пуле
- Password - пароль для воркера (опционально)
- Fee - процент отчислений на данный пул. Может быть от 0.1% до 50%

### Вкладка Boards

На данной вкладке можно отключить слоты хэшплат устройства. Отображает количество слотов, причину их отключения, если таковая имеется, а также опции автовыключения плат при ошибках.

![Скриншот сделанный 2026-08-12 в 13.00.37.png](/images/skrinshot-sdelannyj-2026-08-12-v-130037.png)

- **Auto Disable Slots on Errors** – предназначена для автоматического отключения плат. В случае если плата не начала работу после превышения лимита попыток запуска (устройство перезагружается заданное в **Max Number of Recovery Reboots** количество раз. Если плата не заработала – она отключается);
- **Recovery Reboot Counter** – счетчик количества перезагрузок устройства, связанных с ошибками по плате/платам;
- **Max Number of Recovery Reboots** – количество перезагрузок устройства, связанных с ошибками по плате/платам, после которого проблемная плата будет программно отключена;
- **Limit Boards Power** – отключает использования мощности с выключенных / неработающих плат.

### Вкладка Env Temp Limits

Функция служит для управления работой устройством в зависимости от температуры окружающей среды

![Скриншот сделанный 2026-08-12 в 13.28.45.png](/images/skrinshot-sdelannyj-2026-08-12-v-132845.png)

- **Mining Resume Env Temp** - это поле обозначает температуру окружающей среды при котором устройство выйдет из режима "**Suspended: High Env. Temp**"
- **Mining Suspend Env Temp** - это поле обозначает температуру окружающей среды, когда устройство переходит в режим Suspended. В статусе при этом будет отображаться "**Suspended: High Env. Temp**"

### Вкладка Cool Temp

Настройка **Cool Temp** определяет до какого значения температуры будут охлаждаться платы по время запуска майнера. Все температуры указаны в градусах Цельсия. Конкретное значение зависит от режима выбранного в поле Cool Temp Mode.

![image.png](/images/image-65.png)



- **Default** - используется значение температуры по умолчанию (аналогично заводской прошивке)
- **Manual** - значение температуры задается вручную
- **Env Temp** - используется значение температуры из датчика окружающей температуры

### Вкладка Proxy

Данная функция позволяет использовать промежуточный прокси-сервер, через который будет направляться трафик майнинга

![Скриншот сделанный 2026-08-12 в 13.38.52.png](/images/skrinshot-sdelannyj-2026-08-12-v-133852.png)

- Type - выбор типа прокси сервера. На текущий момент поддерживается только SOCKS5
- Host - адрес прокси-сервера и порт
- User - имя учетной запись для авторизации на прокси-сервере
- Password - пароль учетной записи для авторизации на прокси-сервере
