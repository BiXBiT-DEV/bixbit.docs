# Раздел System

Данный раздел содержит в себе три подраздела:

- **System** - в данном подразделе можно настроить время на устройстве, выбрать часовой пояс и указать адреса NTP-серверов для синхронизации времени в автоматическом режиме
- **Administration** - в данном разделе можно изменить пароль текущей учетной записи
- **Reboot** - раздел, в котором можно выполнить перезагрузку устройства
