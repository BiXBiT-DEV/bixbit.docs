# Установка и обновление прошивки BiXBiT на устройствах Antminer

В скачанном архиве с прошивкой содержится файл **installer_tool.exe** – с помощью этой программы производится установка прошивки BiXBiT. Перед запуском файла требуется предварительно распаковать архив с прошивкой. Сделать это можно с помощью штатных средств Windows (для Windows 11), или любого стороннего архиватора, например, WinRAR.

### Известные проблемы

-  Работа устройства S19 Pro+ Hyd. с хэш-платами  HHB42701, HHB42711 и TH401 не гарантируется ввиду отсутствия тестирования устройств с такими моделями хэш-плат. В случае возникновения нестабильной работы устройств на указанных платах, пожалуйста, обратитесь в техническую поддержку.
- Работа устройств Antminer S21+ Hydro, Antminer S21 XP Hyd., Antminer S21e XP Hyd. на настройках выше заводских не гарантируется ввиду отсутствия стрес-тестирования данных устройств. В случае возникновения нестабильной работы устройств, пожалуйста, обратитесь в техническую поддержку.
- На устройствах с КПУ CV функция Restore factory settings приводит к сбросу прошивки до заводской версии.
- Недоступна установка на устройство L11 с прошивкой FR-1.3(251211-L11&L11 Pro) или новее.
- Переключение типа сетевого соединения на устройстве со Static на DHCP приводит к зависанию устройства. Исправляется только выключением и включением устройства (reboot).

## Запуск и первичная настройка установщика

1. Откройте папку в которую был распакован архив и запустите файл installer_tool.exe
2. В появившемся окне **Firmware File Selection** вы можете:
  - ввести в поле **Firmware File** свой **ID партнера** и нажать кнопку **Check Available FW versions** - в таком случае у вас появится возможность выбрать одну из доступных для вас версий прошивки и загрузить ее, нажав кнопку **Download** – загруженная таким образом прошивка будет в дальнейшем использоваться для установки
  - Нажать кнопку **Cancel** – так установщик будет использовать те файлы, которые были изначально в одном архиве с ним (локальные файлы)
  ![image1.png](/images/image1.png)
3. После откроется основное окно программы:
  ![image.png](/images/image-8.png)
4. Нажмите на кнопку **IP List**, чтобы задать диапазон сканирования сети для поиска устройств, которые желаете прошить.
5. В появившемся окне **Info**:
  - при нажатии кнопки **Да** начальный и конечный IP-адреса диапазона подсети, к которой вы подключены, автоматически добавятся к списку диапазонов установщика. Это может быть полезно если компьютер, с которого будут прошиваться устройства, находится в той же подсети, что и сами прошиваемые устройства  
  - при нажатии кнопки **Нет** откроется пустое окно **Miner IP Management**, в котором нужно будет вручную ввести данные для сканирования сети
6. Для ручного добавления диапазона сканирования сети выполните следующие шаги:
  - Start IP. Задайте начальный IP-адрес из сканируемого диапазона
  - End IP. Задайте конечный IP-адрес из сканируемого диапазона. В случае, когда нужно добавить только один IP-адрес вместо диапазона, то данное поле можно не заполнять
  - HTTP User. Укажите имя пользователя для WEB-интерфейса майнера(-ов)
  - HTTP Pass. Укажите пароль для WEB-интерфейса майнера(-ов)
  - Comment. Задайте название для данного диапазона (не обязательно)
  - Затем нажмите кнопку Add для добавления заданного диапазона

::: info
При добавлении нескольких диапазонов необходимо обращать внимание на то, что IP-адреса в них не должны пересекаться, так как в таком случае программа не даст сохранить новый диапазон
:::

7. Выделите с помощью чекбоксов необходимые диапазоны и нажмите кнопку **OK**.
  ![image.png](/images/image-10.png)
8. После этого, в основном окне программы нажмите кнопку **Scan** и дождитесь завершения сканирования сети

## Установка прошивки BiXBiT на устройства

1. С помощью чекбоксов выберите те устройства, которые желаете прошить
2. В блоке Installation Settings перед прошивкой можно дополнительно указать следующие опции:
  ![image.png](/images/image-11.png)
  - **Parallel Installs** – укажите количество одновременно прошиваемых устройств (от 1 до 10).
  - Чекбокс **Force install on new firmware version** позволяет установить более старую версию прошивки BiXBiT по сравнению с той, что уже установлена на устройстве.
  - Чекбокс **Force install to unknown device models** позволяет попробовать установить прошивку даже если модель устройства не была определена корректно.
  - При нажатии кнопки **Firmware Install Options** появится поле для ввода **AMS key (API-ключ AMS)** - если его ввести, то устройства появятся в AMS практически сразу после установки прошивки, дополнительно API-ключ устанавливать не придется.
  ![image8.png](/images/image8.png)
3. Нажмите кнопку Install. При успешной прошивке устройства в поле Progress появится сообщение с содержанием **“Done. Code: Success: OK!” или “Done. Code: CV: Installed“**. После этого программу можно закрыть
  ![image.png](/images/image-12.png)

::: warning
Важно: после установки прошивки на устройства с платами CVtek рекомендуется использовать кнопку “CV Monitoring” - это позволит автоматически восстанавливать прошивку BiXBiT на таких устройствах после их перезагрузки:

1. Выделите устройства с платами CVtek с помощью чекбоксов[a]
2. Нажмите кнопку “CV Monitoring”
3. Установщик должен оставаться постоянно включенным и находиться в одной сети с устройствами

После выполнения данных действий установщик будет периодически проверять, установлена ли прошивка на устройствах с платами CVtek, и восстанавливать ее в случае необходимости  
:::
