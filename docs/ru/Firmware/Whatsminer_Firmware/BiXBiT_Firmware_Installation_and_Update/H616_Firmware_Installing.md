## 4.3. Установка прошивки на КПУ H616

### 4.3.1. Установка прошивки BiXBiT поверх заводской версии прошивки

#### **Этап 1. Загрузка образа промежуточной версии прошивки на SD-карту:**

- **Шаг 1.** Подготовьте **SD-карту**: Рекомендуется использовать SD-карты объемом **от 2 до 16 ГБ** включительно. Полностью отформатируйте SD-карту с помощью «Управления дисками» Windows ([подробная инструкция по форматированию SD-карты](https://www.google.com/url?q=https://bixbit.io/ru/documentation/rukovodstvo-polzovatelia-whatsminer-asic/prilozhenie-3-vspomogatelnye-instruktsii%234-4-2-formatirovanie-sd-karty&sa=D&source=editors&ust=1781697778977306&usg=AOvVaw3Fa4ldVL2eHNp2CXz_sv-I)).
- **Шаг 2.** Используя программу **«PhoenixCard»** (папка с программой **«PhoenixCard»** находится в архиве с прошивкой), загрузите  образ **"Whatsminer-ALL-Models_X.X.X.X_h616-after20231213.img"** из скачанного архива с прошивкой (**X.X.X.X** - версия прошивки) на SD-карту ([подробная инструкция по записи образа прошивки на SD-карту](https://www.google.com/url?q=https://bixbit.io/ru/documentation/rukovodstvo-polzovatelia-whatsminer-asic/prilozhenie-3-vspomogatelnye-instruktsii%234-4-3-zagruzka-obraza-proshivki-na-sd-kartu&sa=D&source=editors&ust=1781697778977838&usg=AOvVaw0asxk2AUOZ4koNtZaSkod7)).

#### **Этап 2. Прошивка ASIC'а промежуточной версией прошивки с помощью SD-карты:**

- **Шаг 1.** Перед тем как вставить SD-карту, отсоедините кабель питания и дождитесь, пока индикаторы полностью перестанут мигать.
- **Шаг 2.** Вставьте SD-карту и снова подключите кабель питания.
- **Шаг 3.** После завершения процесса прошивки будет гореть только зеленый индикатор. Подождите несколько секунд, затем снова отсоедините кабель питания.
- **Шаг 4.** Убедитесь, что индикаторы полностью погасли, затем извлеките SD-карту.
- **Шаг 5.** Подключите питание.

#### **Этап 3. Установка итоговой версии прошивки BiXBiT.**

Запустите WhatsMinerTool и задайте диапазон сканирования, включающий IP-адрес устройства для установки прошивки. Запустите сканирование и убедитесь, что устройство отображается в списке.

![image.png](/images/image-18.png)

![](<file:/C:/Users/heroh/Downloads/Установка и обновление прошивки BiXBiT/images/image2.jpg>)

- **Шаг 1.** Нажмите **[Upgrade] ①**.
- **Шаг 2.** Нажмите **[Select File] ②**.
- **Шаг 3.** Во всплывающем окне выберите файл  **"Whatsminer-ALL-Models_X.X.X.X.bin**" **③** из скачанного и разархивированного вами ранее архива, (**X.X.X.X** - версия прошивки).
- **Шаг 4.** Подтвердите выбор файла нажав **[Open] ④**.
- **Шаг 5.** Установите флажок **слева от IP-адреса устройства ⑤**, прошивку которого нужно обновить. Можно выбрать несколько устройств, если на них предварительно была установлена промежуточная версия прошивки
- **Шаг 6.** Нажмите кнопку **[Start Upgrade] ⑥**, чтобы запустить процесс обновления. В появившемся диалоговом окне нажмите кнопку **[ОК]**.

::: tip
Отображение статуса Success в столбце Status обновляемого устройства свидетельствует об успешном завершении процесса установки. Далее устройство автоматически перезапустится.
:::
