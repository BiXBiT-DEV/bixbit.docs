## Настройка отображения данных

- Нажмите кнопку **[Settings]** ①
- В пункте **List Column Display Mode** выберите **Complete Mode** ②
- Нажмите **[Save]**  ③

![image.png](/images/image-11.png)

::: info
Примечание: в режиме Complete Mode дополнительно отображаются столбцы с информацией по каждой хэш-плате (модель и ревизия чипов, температура чипов) а также параметры электросети на входе в блок питания, состояние активации некоторых функций.
:::
