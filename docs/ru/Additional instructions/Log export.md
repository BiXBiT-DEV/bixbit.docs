## Antminer

## Whatsminer

Если у вашего устройства возникают сбои или ошибки, вы можете экспортировать   
его логи для анализа поведения устройства и определения причин возникновения данных ошибок. 

### С помощью WhatsminerTool

![image.png](/images/image-79.png)

- **Шаг 1:** Выберите IP-адрес устройства, логи работы которого вы хотите экспортировать. Можно выбрать несколько устройств.
- **Шаг 2:** Перейдите в **[Remote Ctrl]**.
- **Шаг 3:** Выберите **[Export Log]**.
- **Шаг 4:** Подтвердите нажатием **[OK]**.
- **Шаг 5:** В открывшемся диалоговом окне выберите директорию сохранения лого.
- **Шаг 6:** Нажмите **[OK]**, чтобы начать процесс экспорта логов.
  ![image.png](/images/image-80.png)

  

При этом кнопка **[Remote Ctrl]** на время экспорта переименуется в **[Stop]**. Её можно нажать, если вы хотите прервать процесс экспорта логов.

Через некоторое время в выбранной ранее папке появится файл(ы) вида "**192.168.88.79.20220628161335.tgz"**

### Через web-интерфейс устройства на прошивке BiXBiT

- Откройте web-интерфейс устройства
- Перейдите в раздел **Status** -> **Miner Status**
- Нажмите кнопку Download Logs
- Дождитесь окончания процесса "**Preparing logs**" (от 20 секунд до 2 минут)
- Выберите папку для сохранения файла

Файл будет иметь вид "**M60_VK20_2026-08-14_18-18.tgz**"
