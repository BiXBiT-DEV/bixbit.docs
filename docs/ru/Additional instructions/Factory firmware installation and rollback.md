# Установка и откат заводской прошивки

## Antminer

В некоторых случаях для установки прошивки BiXBiT может потребоваться предварительный откат заводской версии прошивки на более старую версию.

::: warning  
Новые версии заводской прошивки датируемые 2025-2026 годом понизить описанным в данной инструкции методом, скорее всего не получится.  
Для отката самых последних версий заводской прошивки на контрольных платах Amlogic можно использовать другой метод отката - через USB-UART  
:::

Для установки или понижения прошивки через прошивку флешкой потребуется:

- Флешка (рекомендуемый объем до 16GB):
  - Для контрольных плат управления Xilinx (zynq 7007), Beagle Bone (BB), CVitek (CV) - MicroSD-карта;
  - Для контрольных плат управления Amlogic (AML) - USB-A флешка или MicroSD-карта и USB OTG переходник с флешки на Micro-USB разъем КПУ;
- ПК или ноутбук с разъемом или переходником для подключения к нему флешки;
- Образ прошивки (можно скачать с нашего хранилища [https://storage.bixbit.io/Antminer_s/SD/](https://storage.bixbit.io/Antminer_s/SD/)).

::: info  
Если стоит цель установить прошивку BiXBiT - то подбирать образ заводской прошивки по модели ASIC-майнера не обязательно, главное выбрать образ под модель контрольной платы управления.  
Для моделей КПУ Amlogic или Xilinx можно использовать universal-образы прошивки, после прошивки КПУ данными универсальными образами ASIC-майнер, скорее-всего, не будет майнить на установленной заводской прошивке, но поверх данной данной заводской прошивки можно будет установить прошивку BiXBiT, на которой модель устройства определится автоматически и устройство сможет майнить.  
:::

Подготовка флешки и загрузка образа прошивки на неё:

1. Подключите флешку к компьютеру или ноутбуку, отформатируйте её (формат файловой системы FAT32).
  ![image.png](/images/image-37.png)
2. Скопируйте содержимое скачанного архива с прошивкой, в корень флешки.
  ![image.png](/images/image-38.png)
3. Отключите питание устройства, дождитесь когда на контрольной плате погаснут светодиодные индикаторы.
4. Подключите флешку с образом прошивки к контрольной плате управления.
5. Включите устройство, подождите завершения прошивки (когда установка прошивки будет завершена, на контрольной плате управления будет постоянно гореть зеленый индикатор).
6. Отключите питание устройства, дождитесь когда на контрольной плате погаснут светодиодные индикаторы.
7. Извлеките ранее подключенную флешку из устройства
8. Включите устройство
